LR CONNECT V3 — COMIENZO RÁPIDO

1. Instala Node.js 20+.
2. Abre una terminal dentro de esta carpeta.
3. Ejecuta: npm install
4. Copia .env.example como .env
5. Pon tu OPENAI_API_KEY en .env
6. Ejecuta: npm run setup:knowledge
7. Copia el OPENAI_VECTOR_STORE_ID que muestra el comando a .env
8. Ejecuta: npm start
9. Abre http://localhost:3000

IMPORTANTE: nunca pongas la API key en el navegador, en index.html ni en un repositorio público.
